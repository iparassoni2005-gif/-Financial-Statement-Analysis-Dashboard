# Financial Statement Reporting & Analysis Dashboard

## Project Overview
An interactive Power BI dashboard for financial statement 
reporting and analysis including P&L, balance sheet KPIs, 
and revenue trends.

## Tools Used
- Power BI
- DAX (Data Analysis Expressions)
- Power Query (ETL)
- Microsoft Excel

## Key Features
- P&L tracking across multiple periods
- Balance sheet KPI monitoring
- Monthly revenue trend analysis
- Automated data transformation using Power Query

## Skills Demonstrated
- Data Visualization
- Financial Analysis
- DAX Measures & Calculations
- ETL Process
