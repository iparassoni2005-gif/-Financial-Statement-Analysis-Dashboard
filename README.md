📌 Project Overview
This project is an interactive Power BI dashboard built to analyze and report financial statements including Profit & Loss (P&L), Balance Sheet KPIs, and Revenue Trends across multiple time periods.
The dashboard enables finance teams and business stakeholders to make data-driven decisions by visualizing complex financial data in a simple and intuitive format.

🎯 Objectives

Track monthly and yearly revenue trends
Monitor Profit & Loss (P&L) across departments
Analyze Balance Sheet KPIs at a glance
Automate manual financial reporting using Power Query ETL
Enable dynamic period comparisons (MoM, YoY, QoQ)


🛠️ Tools & Technologies Used
ToolPurposePower BIDashboard creation & data visualizationDAXCustom measures & KPI calculationsPower QueryData transformation & ETL processMicrosoft ExcelRaw data source & preprocessing

📈 Key Features

✅ Dynamic P&L Report — Track income, expenses, and net profit
✅ Balance Sheet Overview — Assets, liabilities, and equity at a glance
✅ Revenue Trend Analysis — Monthly & yearly revenue comparison
✅ Interactive Filters — Filter by department, time period, and category
✅ Automated ETL — Power Query reduces manual data prep by 60%
✅ Period Comparison — MoM, YoY, QoQ using DAX time intelligence


💡 Key Insights Derived

Identified top 3 expense categories contributing to 70%+ of total costs
Revenue showed consistent 15% YoY growth over analyzed period
Automated data refresh reduced manual reporting time significantly
Balance sheet ratios highlighted areas for financial optimization
